### 채팅 시스템 요구사항

- 요구사항 정리
  - 응답 지연이 낮은 1:1 채팅과 소규모 그룹 채팅 지원
  - 다단말 지원(핸드폰, PC 등) 및 채팅 내역 저장 기능 포함
- 서버 통신 방식 검토
  - 폴링 방식은 비효율적이며, 롱폴링은 서버클라이언트 불일치 문제 존재
  - 웹소켓 방식은 HTTP 핸드셰이크 후 업그레이드하여 양방향 통신 가능
  - 웹소켓은 연결을 영구적으로 유지하며 서버 관리가 필요
- 확장성과 저장 방식
  - 싱글 서버 운영은 단점이 많아 수평 확장 필요
  - 데이터 저장은 일반 데이터와 채팅 이력으로 구분, 키값 소트 방식 권장
  - 롱테일 데이터 접근 지연 문제 존재, 인덱스 접근 방식은 비트리 사용
- 메시지 ID 및 동기화
  - 메시지 ID는 고유하고 시간 순서 정렬 가능해야 하며, 스노우플레이크 등 생성기 사용
  - 동기화는 커런트 렉스 시즈 아이디 방식으로 최신 메시지 인식 및 동기화 처리
- 서버 부하 및 인원 제한
  - 서버 1대당 수천~수만 동시접속 처리 가능
  - 채팅방 인원 제한 존재, 예를 들어 디스코드는 2500명 제한
  - 로드밸런서와 IP 기반 서버 연결 방식으로 특정 서버 접속 보장 어려움
- 게임 서버와 채팅 서버 차이
  - 게임 서버는 IP 기반 접속, 채팅 서버는 특정 채널 메시지 처리 필요
  - 수평 확장보다는 액티브스탠바이 방식 백업 운영 선호

### 대규모 검색어 자동완성

- 요구사항 및 트래픽
  - 활성 사용자 1000만 명, 1인당 평균 검색 10회, 평균 TPS 2만 4000, 최대 4만 8000
  - 신규 검색어 비율 약 20%로 추정
- 자료구조 및 처리 방식
  - 트라이(Trie) 자료구조를 기반으로 접두사 검색 최적화
  - 노드별 상위 5개 후보 캐싱으로 쿼리 비용 절감
  - 실시간 트라이 갱신은 부하가 크므로 로그 수집 후 주기적 빌드 방식 적용
  - 트라이 빌더와 캐시 레이어를 활용해 빠른 검색 응답 제공
- 최적화 및 샤딩
  - 샤딩을 통해 대규모 데이터 분산 처리 가능
  - 자주 검색되는 접두사는 별도 관리, 드문 접두사는 묶어서 처리
  - 클라이언트에서 입력 제한 및 캐싱으로 불필요한 요청 감소 유도
- 다국어 및 특수 검색
  - 유니코드 기반 처리 필수, 다국어 특성에 맞는 로컬라이제이션 필요
  - 한국어는 띄어쓰기, 어순 변화, 품사 이동 등 복잡성 존재
  - 일본어, 중국어는 발음 및 문자 변환 고려 필요
  - 초성 검색 등 특수 검색 기능은 그래프 구조 등 별도 구현 가능성
- 검색어 필터링 및 머신러닝 적용
  - 비속어 및 부적절한 검색어 필터링은 머신러닝 기반으로 처리
  - 키워드 기반 1차 필터링 후 ML 적용으로 효율적 차단
  - 법적 이슈 대응을 위한 필터링 레이어 구성
  - 자동완성 결과에는 필터링 적용하지 않는 경우도 존재
- 광고 및 추천 시스템 연동
  - 자동완성에 광고 삽입 가능성 존재
  - 광고 노출은 별도 알고리즘과 분리 운영
  - 광고 관련 법률 준수 필요

### 개발 환경 및 기술 동향

- 채팅 서버 개발 경험 및 기술 스택
  - TCP 기반 채팅 서비스 구현 경험 권장
  - GRPC, 웹소켓 등 양방향 통신 프로토콜 활용 사례
  - 게임 서버는 심플한 구조, 채팅 서버는 복잡한 수평 확장 문제 존재
- 버전 관리 및 협업 도구
  - 게임사 중심으로 퍼포스(Perforce) 사용, 대규모 파일 관리에 적합
  - SVN, Git 등 도구별 충돌 관리 및 브랜치 전략 차이
- AI 및 LLM 활용
  - 자동완성 및 검색어 추천에 Transformer, BERT 등 경량 모델 활용 가능
  - 로컬 LLM 모델도 CPU 환경에서 빠르게 동작 가능
  - AI 도입은 데이터 품질과 샘플링 중요
- 시스템 운영 및 비용 이슈
  - 서버 확장, 부하 분산, 장애 대응 전략 필요
  - 클라우드 서비스(AWS 등) 활용과 자체 서버 운영 비교
  - 개발 도구 및 라이선스 비용 부담 존재
  - 인건비와 AI 비용 간의 경제성 고려
- 한국어 NLP 특성
  - 한국어는 품사 이동 자유로움, 띄어쓰기 문제 등으로 NLP 난이도 높음
  - 별도의 한국어 NLP 연구 및 도서 존재
  - 다국어 지원 시 각 언어별 특수성 반영 필요
